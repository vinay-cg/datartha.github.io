Program structure

Eight live touchpoints across three weekends.

The program includes six instructional sessions, a guided project and a doubt-clearing and office-hours session.

01

AI Foundations for Data Professionals

LLMs, context, prompting, model choice, responsible use, privacy and security.

02

AI Productivity for Data Work

SQL, Python and shell scripting, troubleshooting, root-cause analysis, documentation and data analysis.

03

AI-Assisted Engineering

Claude Code, Codex, Cursor, repository context, debugging, testing, refactoring and review.

04

Agentic AI

Agents, tools, planning, memory, state, guardrails, permissions, failure handling and human review.

05

GenAI Applications and Self-Hosted LLMs

APIs, structured outputs, tool calling, embeddings, vector databases, RAG and model hosting.

06

Enterprise AI Systems

Architecture, security, access control, evaluation, observability, reliability, latency and cost.

07

Guided DIY Project

Choose a problem, design the workflow, build a first version, add intelligence, test, refine and demonstrate it.

08

Doubt Clearing and Office Hours

Bring a real problem for troubleshooting, architecture review, reliability review and next-step planning.
